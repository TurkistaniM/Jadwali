## 🌟 نبذة عن المشروع
**جَدْوَلي** هي منصة أكاديمية متكاملة مصممة خصيصاً لطلاب الجامعات لتوفير تجربة سلسة وعصرية في إدارة حياتهم الأكاديمية اليومية، وربط كافة البيانات الدراسية بقاعدة بيانات سحابية مشفرة وآمنة مع دعم كامل للعمل دون اتصال بالإنترنت (Offline First).

## ✨ أبرز المميزات

### 1️⃣ 📚 إدارة المقررات والجدول الدراسي
- إضافة وتنظيم المقررات الدراسية واختيار أيام المحاضرات (أحد إلى خميس).
- **الحساب الذكي لأوقات المحاضرات:**
  - `50 دقيقة` تلقائياً للمحاضرات ذات الـ 3 أيام (مثل: أحد، ثلاثاء، خميس).
  - `ساعة و 15 دقيقة` تلقائياً للمحاضرات ذات اليومين (مثل: اثنين، أربعاء).
- تدوين أرقام المباني، القاعات، واسم المحاضر، وطرق التواصل المباشر (بريد، واتساب، جوال).

### 2️⃣ 📊 خوارزمية الغياب المنقضي (Smart Absence Tracker)
- حساب نسبة الغياب الفعلية بناءً على **المحاضرات المنقضية فقط** من بداية الفصل الدراسي بدلاً من إجمالي الفصل.
- تحديد دقيق لساعات الحرمان (10%، 20%، 25%).
- إمكانية استعراض المحاضرات السابقة وتعديل حالتها بنقرة واحدة (`حاضر`، `غائب`، `متأخر`، `تم إلغاء الدرس`).

### 3️⃣ 💰 عدّاد وسجل المكافأة الجامعية
- عدّاد تنازلي حي بالثواني لموعد إيداع المكافأة الجامعية.
- تطبيق قواعد التقويم المالي السعودي:
  - الإيداع يوم **27** من كل شهر ميلادي.
  - تقديم الإيداع للخميس 26 إذا وافق يوم 27 الجمعة.
  - تأخير الإيداع للأحد 28 إذا وافق يوم 27 السبت.
- **تخصيص المبلغ الشهري:** اختيار فوري حسب التخصص (`990 ر.س` علمي، `840 ر.س` أدبي، `1000 ر.س` صحي، أو أي مبلغ مخصص).
- سجل تاريخي لإيداعات المكافأة مع إمكانية إضافة وتعديل الحوالات السابقة.

### 4️⃣ 📝 المهام والاختبارات الأكاديمية
- تتبع الواجبات والمشاريع مع خاصية تمييز المهام المهمة بنجمة ⭐.
- جدول زمني تفاعلي للاختبارات الدورية والنهائية ومواقع لجان الاختبار.

### 5️⃣ 👤 الملف الأكاديمي والمعدل التراكمي
- دعم كافة أنظمة المعدل الجامعي (`من 5.00`، `من 4.00`، ونظام `النسبة المئوية %`).
- شريط مرئي للمعدل وتحديد مراتب الشرف الأكاديمية.
- ضبط تواريخ بداية ونهاية الفصل الدراسي لضبط دقة الخوارزميات.

### 6️⃣ 🔒 الأمان وتعدد طرق تسجيل الدخول
- دعم تسجيل الدخول عبر **البريد الإلكتروني** أو **الرقم الجامعي**.
- ربط سحابي كامل مدعوم بسياسات الأمان الصارمة **(Row Level Security - RLS)** في Supabase لضمان خصوصية بيانات كل طالب.
- نظام تخزين مؤقت محلي (Dual Cache) يضمن عدم فقدان أي بيانات عند تحديث الصفحة أو انقطاع الإنترنت.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** [React 18](https://react.dev/), [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/)

- **Backend & Auth:** [Supabase](https://supabase.com/) (PostgreSQL, Auth, RLS Policies)
- **Deployment:** [Render](https://render.com/) & [GitHub](https://github.com/)
