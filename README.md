# جَدْوَلي - منصة الطالب الجامعي الشاملة (Student Portal)

تطبيق ويب متكامل ومرحب للطلاب الجامعيين لتنظيم جدولهم الدراسي، الحضور، والمهام والمكافآت.

## المتطلبات والأمان:
- **Responsive:** Fully responsive on desktop, tablet, and mobile.
- **RLS:** Each user can only read and modify their own data using Supabase Row Level Security (RLS).
- **Deployment:** Automatic Deployment on Render via GitHub push.
- **Environment:** `.env` file MUST NOT be pushed to GitHub. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` on Render Dashboard.
